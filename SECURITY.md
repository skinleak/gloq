# Security Policy

## Supported versions

Security fixes are provided for the latest released version of gloq.

## Reporting a vulnerability

Please do not open a public issue for a suspected vulnerability. Use
[GitHub's private vulnerability reporting](https://github.com/skinleak/gloq/security/advisories/new)
instead.

Include the affected version, impact, reproduction steps, and any suggested
mitigation. You should receive an acknowledgement within seven days. Please
allow time for a fix and coordinated disclosure before publishing details.
